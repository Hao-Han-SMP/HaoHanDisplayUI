# HaoHan Display UI

HaoHan Display UI is a Paper and Purpur plugin for creating interactive interfaces directly inside the Minecraft world.

It gives plugin developers a simple API for combining text, items, blocks, panels, and clickable buttons with Display Entities. The engine handles rendering and interaction, while the plugin using it decides what the interface should do.

It can be used to build machine panels, guide boards, item lists, paginated menus, command buttons, documentation links, and private interfaces for individual players.

> This is an engine for other plugins, not a ready-made gameplay menu. Install it when another plugin requires it, or use the included demo to see what it can do.

## Main features

- Text, item, and block Display Entities
- Rich text, RGB colors, gradients, and text styles
- Icons, lists, layered panels, and flexible alignment
- Clickable buttons and hover descriptions
- URL, player command, console command, and suggested command actions
- Fixed, rotated, or camera-facing interfaces
- Per-player visibility and distance limits
- Scene updates, movement, and automatic cleanup
- No client mod required

## Compatibility

- Minecraft `1.20+` (1.20.4 – 1.21.x+)
- Paper and Purpur
- Java 21 or newer
- Server-side only
- Resource pack optional

## Try the demo

Run the following command in game:

```text
/hhdui demo
```

The demo shows text styles, item lists, clickable rows, camera modes, rotations, URLs, and command actions.
